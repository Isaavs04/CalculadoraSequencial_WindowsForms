# CalculadoraSequencial_WindowsForms
Calculadora sequencial: uma calculadora que resolve as operações na ordem em que são digitadas.

## ✦ Sobre
Projeto pessoal realizado baseado no projeto de calculadora proposto em sala de aula, na matéria de programação orientada a objetos(POO)

- **Interface:** Windows Forms (WinForms)
- **IDE:** Visual Studio


## ✦ Funcionalidades
- [x] Operações matemáticas básicas (Adição, Subtração, Multiplicação e Divisão).
- [x] Execução de cálculos sequenciais.
- [x] Botão de limpar visor (Clear).
- [x] Tratamento de erros para divisões por zero.
